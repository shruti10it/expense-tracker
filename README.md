# 💰 Expense Tracker Dashboard

A simple Expense Tracker project built using Python and Streamlit.

## Features

- Add new expenses
- Select expense category
- Add expense description
- View total expenses
- View total number of entries
- View all expenses in a table
- Category-wise expense bar chart
- Delete selected expense
- Clear all expenses

## Technologies Used

- Python
- Streamlit
- JSON
- VS Code

## How to Run

1. Install Streamlit:

   pip install streamlit

2. Run the dashboard:

   streamlit run dashboard.py

3. The Expense Tracker Dashboard will open in the browser.

## Project Purpose

The purpose of this project is to provide a simple and interactive way to record, view, analyse and manage daily expenses.
